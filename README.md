# dfr-onboarding

[DFR](https://dallasformularacing.com) embedded onboarding work for 2026.

This repository follows [this](https://github.com/DallasFormulaRacing/embedded-onboarding) onboarding guide.

Answers to exercises are organized by section, then the subfolder for the given exercise. Since this is not a clone of the embedded-onboarding repo, some files had to be mass copy-pasta'd into this project. Apologies if stuff seems a little wonky.

I have included personal notes about each project either in the comments of the exercise itself, as README files in each exercise, or as a README file for the entire section. These notes are for future reference as they document problems I may have encountered and the solution I found to them.

The development board I used was the STM32 NUCLEO-F030R8 rev C (the same one suggested in the DFR guide). Unless otherwise stated this is the board that the code should run on.
